Общий оборот последней полной недели — **1 055 653 508,75 ₽**, доходность после товарных потерь — **22,29%**. Доходность определена как (оборот − себестоимость − потери) / оборот, без операционных затрат. Оборот на склад использует среднее число складов за 7 дней.

В месячной динамике мая количество заказов на склад выросло на 4,25%, средний чек снизился на 3,84%, оборот на склад почти не изменился (+0,25%). Доля потерь выросла с 0,421% до 0,578%, запас — на 2,81%. Подробные выводы и ограничения приведены в записке.

## Использование

В Excel начните с «Итогов», затем откройте «Динамику». На «Сводной» находится редактируемый объект PivotTable, на «Неделях и территориях» — прозрачные расчёты SUMIFS. Для обновления сводной после правок выберите Данные → Обновить всё. Источник фиксирован на 504 строки; при добавлении данных диапазоны нужно расширить. В русской локализации Excel имена формул отображаются автоматически.

[Скачать полный проект с исходниками и данными](samokat-1-a-complete.zip). Архив содержит папки src, docs, sql, input и output, зависимости и инструкции по пересборке. Описанные в конспекте пути относятся к структуре внутри архива.

## Проверка и допущения

Проверены ключи, все 504 объединённые строки, недельные суммы, рейтинги и структура нативной сводной. Расчёты сверены независимым Python-кодом. SQL проверяется на синтетических примерах после преобразования T-SQL в DuckDB; реального SQL Server и фактов SQL-части нет. Настольный Excel и интерактивное обновление PivotTable не запускались. Нативная сводная добавлена через OOXML из-за ограничений экспорта библиотеки; расчётные листы содержат формулы и сохранённые результаты.

Пропуски территорий не доказаны как нули. Клиенто-дни не являются уникальными клиентами недели. У исходного графика запаса конфликт единиц, поэтому в записке используются относительные изменения. Условия дат закрытия складов, базы SKU и обработки равных рейтингов явно описаны в конспекте и SQL.
